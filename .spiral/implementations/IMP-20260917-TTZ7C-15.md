# Implementation: Index Finalization Dispatch

The default index object exposes `finalize(serialized, meta, uuid = null)`,
delegating to the existing serialized offset writer. The named `finalizeIndex`
export chooses a configured finalizer or that default and calls it with the
configured object as receiver. It forwards the result/promise unchanged.
This keeps frozen objects and inherited methods usable without mutating the
configured module or merging defaults into it.

The converter and command worker await this dispatcher at their existing
post-write boundary. Their governed implementations are updated separately.
Existing create/update/load implementations are unchanged. A custom finalizer
replaces the default, and can delegate explicitly to retain standard offsets.

README documents the optional contract, argument types, default fallback,
receiver, awaiting, read-only input expectation, and failure limits. No
dependency, on-disk format, or downstream wrapper change is introduced.
