# Implementation: Serialized Command Offset Finalization

The command worker awaits `finalizeIndex` after persisting the
changeset and before integrity recording and its existing after-write fault
point. Configured finalizers receive the serialized bytes, metadata, and command
ID with their original receiver. Missing finalizers fall back to the default
shared writer. The shared writer scans final bytes, includes records introduced by
custom hooks, respects skipped record numbers, and atomically replaces the
sidecar. Empty input produces an empty index. Write failures propagate through
the existing command failure path.

`scanOdJsonTagRecords` extracts the existing recovery framing loop and adds
record-number tracking plus an optional visitor. `assertOdJsonTagFraming`
delegates without allocating offsets or parsing payloads. Existing validation
errors and integrity/status semantics are retained. The converter now shares
this writer; its separately governed implementation lineage is updated.

All six command-worker regressions failed before implementation, reproducing
stale existing positions, absent new and hook-created records, incorrect
successive changesets, stale no-op indexes, and missing final-write failure.
A server-level test additionally checks that final-write failure leaves the
command failed and the previous committed state visible and reconstructable.

The latest revision replaces direct offset-writer dispatch with optional
configured finalization. Tests now also cover asynchronous delegation, custom
replacement without an unconditional default write, rejection propagation, and
server-level rejection keeping the previous committed state reconstructable.
The shared scanner and writer themselves are unchanged in this revision.

The legacy custom create/update interface remains callable. Such hooks can
still leave provisional files when they fail; the final pass guarantees the
index for successful conversion/commands. No new transaction framework or
on-disk format is introduced. No package release or downstream repair occurs.
