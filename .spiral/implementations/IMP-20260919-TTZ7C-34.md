# Implementation: Dependency Manifests Match Shipped Code

Implements the dependency correction in DES-20260919-TTZ7C-32 after verifying
imports, installed package contents, current compatible releases and audit output.

The root manifest removes `codemirror`, `write-file-atomic` and `process`.
SimplyStore serves its checked-in CodeMirror web assets, uses `src/storage.mjs`
for durable publication and imports Node's built-in `node:process`; none of the
removed packages is imported by shipped or test code. The VM2 range now declares
the installed 3.12.2 patch. ESLint, `@eslint/js` and `globals` advance to their
current Node-24-compatible majors, and the existing flat configuration continues
to lint the changed runtime files without modification.

The example updates its direct JSONTag and UUID dependencies and removes unused
ESLint. `@muze-nl/jsontag-types` still declares UUID 8 even though its installed
source does not import the UUID package; a scoped override selects UUID 14.0.2
for that unused declaration. The example's own `v4()` import runs with UUID 14.
Both root and example installations report zero npm audit findings.

The default `npm test` script now includes the focused runtime tests. Root and
example lock files remain intentionally ignored by the repository; local locks
were regenerated during clean-install verification and agree with the manifests.

A clean temporary repository copy installed both packages, built the example,
started it, served a JSON query, accepted an example UUID command and reported
that command `done`. Existing generated files in the working example were not
modified.
