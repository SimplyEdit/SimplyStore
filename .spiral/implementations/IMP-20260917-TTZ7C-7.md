# Implementation: Final Conversion Offsets

`scripts/convert.mjs` reparses the final serialization after writing it and
regenerates the offset sidecar through the existing writer with fresh positions.
The legacy custom create hook still runs once. No format or CLI changes.

`test/conversion-offsets.mjs` exercises the CLI and independently walks UTF-8
record framing. Before the fix, default conversion passed while the two custom
hook cases failed: a changed record ended at byte 121 but its stored range ended
at byte 61, and a hook writing no sidecar left the previous index untouched.
The tests also cover shrinking text, hidden reference properties, appended
records, and stale extra entries. They are included in `npm test`.

This previously ungoverned converter has no prior implementation artifact to
transform. Its existing hook/write behavior was characterized directly from
source and the failing CLI probes. Command-update indexing remains out of scope.
