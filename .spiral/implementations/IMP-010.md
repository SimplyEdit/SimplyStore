# Implementation: Causal Provenance Repair And Validation

## Scope and effective provenance

Preserve the CYC-016 causal repair and extend its validator under
`DES-20260916-TTZ7C-2`. The implementation is development tooling; SimplyStore
runtime behavior and package dependencies are unchanged.

## Observable behavior

- `scripts/validate-spiral-provenance.py` parses RDF with rdflib and checks exact
  target definitions, paths, full hashes, and admissible ancestry.
- `scripts/validate-spiral-provenance.mjs` preserves the Node entry point and
  delegates to that parser; `PYTHON` selects the interpreter when necessary.
- Default / `--tree` validates committed snapshots; `--staged` reads the index;
  `--range base..head` audits introduced artifact versions, even if later removed.
- `--range HEAD` audits all reachable history without suppressing known violations.
- External culture/profile references resolve through the source version's
  pinned core repository; process Turtle is not part of the project graph.
- `test/spiral-provenance.py` exercises the failure modes with disposable Git histories.
- `scripts/hooks/pre-commit` provides opt-in local prevention. CI runs range and
  snapshot validation alongside the pinned core integration validator.

## Lineage and correction meaning

The Turtle projection retains the immediate predecessor and the correction
design as transition cause. The validator's semantics change; the product's
semantics do not. Old partial-parser claims remain historical evidence and are
superseded by this implementation. No old commit is amended or relabelled valid.

## Dependencies and limits

rdflib is already required by the pinned Spiral core; no runtime dependency was
added. The validator does not replace the core coherence/integration checks or
human judgment about intent, implementation ownership, or acceptance. There are
no SHACL shapes in the pinned core. Old invalid references remain visible to raw
history audits. Current validity does not imply pristine history.
