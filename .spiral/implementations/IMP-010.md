# Implementation: Causal Provenance Graph Repair And Validator

## Scope

Process-only provenance repair for the Spiral graph plus a repository-local validator that mechanically checks representative causal traversals.

## Observable behavior

- Current effective provenance for representative durability and handler artifacts can be traversed from implementation to design, request, understanding, and retained human source.
- Historical implementation lineage remains separate through `sd:transforms` and `sd:changeCausedBy`.
- Machine-readable historical references use full 40-character Git commit hashes.
- `.spiral/evidence/EVD-008.ttl` no longer contains a shortened Git hash.
- `node scripts/validate-spiral-provenance.mjs` parses the repository's current Spiral Turtle subset, validates historical Git references, checks strict ancestry, checks branch/cycle consistency, and demonstrates the requested traversal examples.
- After cycle acceptance, the validator accepts CYC-016 as either the current active cycle or the latest accepted cycle in project context.

## Effective provenance

This implementation realizes `CYC-016` as a current effective causal interpretation of why the existing durability and handler implementation concerns remain present.

It does not claim that the original code was historically produced from graph links that did not exist at the time. Historical/change provenance is preserved separately with `sd:transforms`, `sd:changeCausedBy`, and existing verification evidence.

This revision also corrects the validator's branch/cycle consistency check so CYC-016 can validate after human acceptance marks it accepted rather than active.

## Important implementation decisions

- No SimplyStore product/runtime code changed.
- The early source, understanding, request, and design artifacts were versioned in separate commits so strict-ancestor references can be expressed honestly.
- Representative current implementation projections were updated rather than rewriting historical artifacts.
- The validator is dependency-free and repository-local so it can run in the current project without adding package dependencies.

## New dependencies / capabilities / permissions

No new package dependencies.

## Known limits

- The validator is a repository-local parser for the current Spiral Turtle subset, not a general standards-conformant Turtle parser.
- The repair covers representative durability and after-change paths required by `CYC-016`; it does not attempt to make every historical or process artifact answer every possible intent query.
- Some remaining provenance questions still require reading artifact prose, especially where the graph distinguishes current effective justification from historical transition causes but does not encode a single artificial linear cause.
