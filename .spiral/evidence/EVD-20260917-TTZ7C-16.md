# Evidence: Configured Index Finalization

Verified on 2026-09-17 with Node v24.7.0.

## Regression And Lifecycle Checks

Before implementation, all five focused custom-finalization tests failed:
conversion and commands ignored the configured finalizer, including rejection.
After implementation all 59 tests passed:

- `npm test`: 33 startup, conversion, and command-offset tests.
- `npm run test:handlers`: 5 tests, including custom finalizer rejection keeping
  the prior committed state visible and independently reconstructable.
- `npm run test:acid`: 5 tests.
- `npm run test:durability`: 16 crash/recovery, timeout, retry, and integrity tests.

Focused tests verify asynchronous completion, receiver and argument preservation,
explicit delegation to default offsets, replacement without an unconditional
default write, rejection propagation, and fallback for frozen legacy wrappers.
An additional direct dispatcher probe verified an inherited finalizer on a
frozen object, preserving its receiver, default UUID, and returned promise value.

Scoped ESLint on `src/index.mjs`, conversion and command offset tests, and handler
tests passed. Staged provenance and whitespace checks passed before committing
the implementation. Process/socket suites used sandbox escalation.

## Curriculum-Store Compatibility

A disposable miniature curriculum graph exercised the actual downstream
`index.mjs`, parent, root, niveau, and utility source files copied byte-for-byte
from `curriculum-restapi-dev/curriculum-store/src`. The fixture linked SimplyStore
to this checkout and shared its JSONTag/OD-JSONTag dependencies. No source edits
were made to the copied wrapper, which still has no `finalize` method.

Conversion and a command that lengthened a child title both produced offsets
matching an independent byte-framing oracle. Conversion preserved the expected
parent, root, and niveau links; replaying the command changeset preserved the
new title and niveau index. Temporary data was removed afterward.

The initial direct cross-checkout probe failed before finalization because the
installed old SimplyStore and this checkout resolved distinct OD-JSONTag symbol
instances: the old offset writer could not see the parsed entity's position.
The shared-dependency fixture avoids that test-environment mismatch and verifies
unchanged wrapper source against the fixed dependency; it does not prove that
mixing arbitrary installed dependency copies works. Installed downstream
dependencies and data were not changed.

## Limits

This refines dispatch only; the previously verified final-byte scanner remains
unchanged. Custom finalizers own their output and must delegate to retain default
offset files. Read-only finalization inputs are a documented contract, not an
enforced sandbox. Failure can leave uncommitted files, not a partial successful
command. Existing stale sidecars are not repaired automatically. No release,
downstream installation, merge, or human acceptance is claimed.
