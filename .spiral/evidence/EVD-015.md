## Failure cases / limits

- This evidence does not validate SimplyStore runtime behavior; no runtime code changed in this cycle.
- The validator is a repository-local parser for the current Spiral Turtle subset, not a general RDF/Turtle conformance tool.
- The repair validates representative implementation paths required by `CYC-016`; it does not prove every historical or process artifact can answer every possible intent query.
- Some answers remain intentionally non-linear: current effective justification, predecessor transformation, change cause, and verification evidence are separate surviving reasons rather than one collapsed chain.
- Human prose remains useful where the machine graph can identify related artifacts but not fully explain why the current-effective interpretation is the right one.

## Evidence quality

This is strong evidence for the specific Spiral claim under test in `CYC-016`: the representative machine-readable graph can now answer "why does this code exist?" back to retained human source while preserving separate historical/change evidence.
