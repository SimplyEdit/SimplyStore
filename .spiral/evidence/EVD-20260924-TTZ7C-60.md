## Limits and next boundary

Queries use 64 MiB isolate memory and 10 MiB result limits by default, configurable
with positive validated bounds. Native memory limits are not whole-process RSS
limits. Worker threads still share the server process; OS process isolation,
broader adversarial review and concurrent deployment capacity remain outside
this evaluated slice. No snapshots are used. Trusted storage/command code and
the accepted parser revision remain unchanged in role; portable od-jsontag is
separate work, not a silently published dependency.

Source SRC-57, request REQ-58 and design DES-59 retain the rationale. The cycle
continues the roadmap's sandbox replacement. Queryable object history and audit
metadata remain the next target after this cycle's review/integration; UI is not
required for that target.
