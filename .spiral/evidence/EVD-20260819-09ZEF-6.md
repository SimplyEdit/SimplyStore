# Verification Evidence: Well-Formed OD-JSONTag Alteration Is Currently Trusted

## Claim being checked

Current SimplyStore startup validation detects malformed OD-JSONTag framing, but does not detect a same-length payload alteration that preserves valid framing.

## Why this evidence exists

CYC-20260819-09ZEF-5 is about the first simple integrity-detection behavior for durable OD-JSONTag data. Before changing runtime behavior, Spiral requires current effective behavior and the evidenced gap to be established.

## Design concern observed

`DES-001` defines D6 detectable corruption: malformed, missing, truncated, or inconsistent durable artifacts must not silently become valid state. Earlier evidence covered malformed framing. This probe checks a narrower remaining gap: well-formed altered content.

## Result

Command run:

```text
node --input-type=module - <<'NODE'
import assert from 'node:assert/strict'
import JSONTag from '@muze-nl/jsontag'
import Parser from '@muze-nl/od-jsontag/src/parse.mjs'
import serialize from '@muze-nl/od-jsontag/src/serialize.mjs'
import { assertOdJsonTagFraming } from './src/recovery.mjs'

const original = Buffer.from(serialize(JSONTag.parse('{"persons":[{"name":"Ada"}]}')))
const altered = Buffer.from(original.toString('utf8').replace('Ada', 'Eve'))
assert.equal(original.length, altered.length)
assertOdJsonTagFraming(altered, 'altered-data.jsontag', 'base OD-JSONTag data')
const data = new Parser().parse(altered)
console.log(JSON.stringify({loadedName: data.persons[0].name, bytesChanged: Buffer.compare(original, altered) !== 0}))
NODE
```

Observed output:

```text
{"loadedName":"Eve","bytesChanged":true}
```

Interpretation:

- The durable bytes changed.
- The OD-JSONTag frame lengths remained valid.
- `assertOdJsonTagFraming()` accepted the altered buffer.
- The parser loaded the altered value as ordinary data.

## Failure cases / limits

This is a targeted baseline probe, not a complete corruption matrix. It does not check command status/log tampering, schema tampering, different-length payload alterations, missing integrity metadata, backward compatibility behavior, or automatic recovery.

## Evidence quality

The evidence is sufficient to establish a concrete current-behavior gap before product modification: SimplyStore currently trusts well-formed altered OD-JSONTag payload bytes when no stronger integrity metadata exists.
