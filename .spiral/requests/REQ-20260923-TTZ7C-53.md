# Mandatory integrity

All normal conversion, store opening, file loading and committed publication
require hashes of canonical data and present standard ID/offset sidecars.
There is no opt-out; only the manifest location remains configurable.
Keep direct index trust, missing-index reconstruction and explicit maintenance.
Hash mismatch or missing required evidence fails before successful publication.

Provide explicit initialization for stopped existing stores lacking a manifest.
Validate committed history, framing, IDs and available index consistency; do not
replay commands, rewrite data, replace an existing manifest or claim to establish
historical correctness. Refuse uncertain stores and concurrent ownership.

Batch each committed artifact set into one durable manifest append; reuse the
already verified canonical digest. Measure added command latency against the
accepted optional implementation. Preserve durability, recovery and user files.
