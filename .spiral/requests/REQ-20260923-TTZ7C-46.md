# File-backed operation with durable compatibility

Replace retained/transferred dataset byte buffers with ordered immutable file
sources. Queries lazily read indexed records, including ID lookups before any
traversal. Commands use the exact committed prefix and publish new sources only
after durable completion. Reinitialization, failure, timeout and shutdown release
owned handles. Administrative replay uses the same source contract.

Preserve remote query/command behavior, disk framing and log-authoritative
ordering, integrity validation, custom index finalization and recovery rules.
Missing indexes remain reconstructable; offset framing and configured data
integrity checks remain in force. Validation must not load whole
data files merely to hash them. No production data rewrites or format migration.

Evidence: existing regression suite plus direct file lifecycle, partial-ID-read,
sparse update, worker publication/replacement, malformed framing/integrity and
large-file memory tests. Internal worker messages may change. New dependency
revision must be reproducible. No sandbox/audit/rebuild feature in this cycle.

## Trusted committed ID indexes

Normal startup reads index.id.json and committed-command ID sidecars directly,
without extracting record IDs again. Make index publication reliable instead of
reconstructing IDs to validate them on every startup. ID indexes describe final
serialized bytes after mutation hooks and must be durable before command success.
Index-write failure must prevent success. Runtime ID lookup and restart must agree.

Replacing a record removes its previous ID mapping before applying the new one.
Renames, ID removal and atomic ID swaps must work. Duplicate IDs on distinct
current records are errors; replacement of the same record may retain its ID.
Reject duplicate-ID commands before publishing their canonical changeset.

Reconstruct missing indexes. Provide explicit validation and reconstruction for
maintenance; present malformed indexes fail clearly. Structurally valid indexes
are trusted in normal operation, including completeness. No silent content
comparison or legacy index compatibility is required. The maintainer explicitly
confirmed this is not yet used. Preserve OD-JSONTag/log formats and ordinary
custom hook calls; canonical ID publication belongs to the core commit boundary.
