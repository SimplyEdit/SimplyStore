# Request: Correct Conversion Offsets

The maintainer explicitly requested fixing SimplyStore's offset-index code
after a read-only verification of curriculum-store's generated files found
offsets describing the data before derived fields were serialized. The current
conversation is the direct source; the cycle retains the operative quotation.

Successful conversion must produce `index.offset.json` with one exact UTF-8
byte range per record of the final output file, including records changed or
introduced by the custom `index.create(data, meta)` hook. Its ranges must allow
reading complete record payloads without stale boundaries or missing entries.

Preserve existing CLI arguments, custom-hook invocation, OD-JSONTag framing,
and the offset sidecar's JSON shape. Verify both default and mutating custom
hooks. Existing curriculum-store files and package publication are out of scope.
