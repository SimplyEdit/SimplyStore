# Cycle: Persisted Offset Indexes

Branch: `spiral/CYC-20260917-TTZ7C-4-conversion-offsets`, created from clean
`master` and verified on 2026-09-17.

## Commitment And Evidence

After verification found 181,723 of 181,724 persisted offsets incorrect in the
local curriculum-store dataset, the maintainer clarified: "the offset index
code is incorrect, i want to correct that code, in simplystore first."
The ID index was correct. Inspection of SimplyStore's converter confirms that
index creation precedes the final serialization, although custom index hooks
can change record sizes. This request authorizes fixing that evidenced defect.

## Goal And Scope

Make conversion persist offsets matching the final OD-JSONTag output after
custom indexing. Preserve the CLI, custom create hook, and disk format. Verify
default conversion and hooks that grow, shrink, and add records, including
multibyte text. Do not change curriculum-store data or publish a package in
this cycle.

On 2026-09-17 the maintainer extended the goal to command changesets after a
worker probe reproduced stale offsets and a missing new-entity entry, saying
"But it needs fixing ...". This is an explicit re-plan of the active cycle:
both conversion and successful commands must publish offsets derived from
their final serialized bytes. Preserve sparse changeset record numbers,
pre-serialization custom mutations, integrity recording, and failure behavior.

The maintainer subsequently approved routing finalization through the index
module so curriculum-store's customized methods work out of the box. Add an
optional finalization hook with a default fallback for existing wrappers;
preserve the current create/update/load contracts. This is a further explicit
scope refinement within the same active cycle.
