# Self-healing store ownership

Goal: REQ-20260926-TTZ7C-66. A stop during startup releases ownership, and a
crashed owner that is proven gone no longer needs manual lock release.

Status: Accepted on 2026-09-26. Human commitment in SRC-20260926-TTZ7C-65: the maintainer asked
for self-healing, reviewed the complexity estimate, and chose this cycle as the
SimplyStore part of a chain ending in curriculum-restapi-dev's
CYC-20260926-1ZG1H-6.

Classification: deliberate deviation from ROADMAP.md; object history remains
the next target. It revises the accepted ownership rule of
DES-20260919-TTZ7C-24 through that design's named kernel-backed alternative,
by explicit maintainer decision.

Branch: spiral/CYC-20260926-TTZ7C-67-self-healing-ownership, created from
authoritative master 039748e (SimplyStore 0.11.1). Branch identity checked when
opening the cycle.

In scope: ownership liveness and takeover, startup signal handling, the
administrator unlock's handling of the new lock contents, tests (including the
existing crash-ownership test, whose expectation changes from the lock to the
unfinished command), recovery and durability documentation.

Non-goals: automatic restart, automatic command recovery, multi-machine
stores, native lock dependencies, a release (the maintainer publishes), and
changes in curriculum-store or curriculum-restapi-dev.

## Evaluation ready

The goal can be judged. A server takes over the lock of a runtime owner whose
liveness socket refuses connections, audited and serialized, then applies the
unchanged startup assessment; all other locks still need administrator
release. Stops during startup release ownership. EVD-20260926-TTZ7C-68 records
the regressions, 215 passing tests, and a Docker run through the actual
compose file: after SIGKILL the next `up` heals and serves.

Retained for later: Windows and socket-less filesystems keep manual release;
real-device power loss is not exercised; SimplyStore's release is the
maintainer's; curriculum-store's lockfile and curriculum-restapi-dev's pin and
end-to-end evaluation follow in CYC-20260926-1ZG1H-6. Existing 0.11.1 locks,
including the local dataset's, still need one administrator release.
