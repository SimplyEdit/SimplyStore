# Schema identity across the query isolate

Goal: restore object identity for non-record objects across the query isolate
boundary, so `meta.schema` queries work and shared schema objects keep their
JSONTag links. Correct DEF-20260926-TTZ7C-62.

Status: Accepted on 2026-09-26. Human commitment: the maintainer confirmed the understanding
and defect cycle on 2026-09-26 and set the identity direction retained in
SRC-20260926-TTZ7C-61: each object gets a stable identifier that outlives a
single query and is not exposed to query code.

Classification: deliberate deviation from ROADMAP.md. Object history remains
the next roadmap target. This defect is in accepted, integrated work from
CYC-20260924-TTZ7C-56 and blocks curriculum-store's SimplyStore 0.11 upgrade.

Branch: spiral/CYC-20260926-TTZ7C-63-schema-identity, created from
authoritative master bd61d9c. Branch identity checked when opening the cycle.

In scope: the identity rule in DES-20260924-TTZ7C-59, its implementation in the
query view/guest bridge, a regression with a shared and cyclic schema, and
measurement of the curriculum-store schema through the real runtime. Guest-side
read caching is in scope only if measurements show identity alone leaves the
query outside its limits.

Scope refinement during Act: with stable handles, curriculum-store's full
schema returns as JSON in 2.7 s, above the 1 s default timeout, while the host
serializes it in 11 ms. Guest-side read caching is therefore in scope. JSONTag
responses failed because the schema reaches workers without its JSONTag ids;
per the maintainer's decision in SRC-20260926-TTZ7C-61, query workers receive
and parse the schema's original JSONTag text.

Non-goals: object history, schema editing, changes to data record identity,
query limits or grants, curriculum-store's own Spiral repair and unrelated
cleanup.

## Goal extension

On 2026-09-26, after evaluation-ready evidence for the schema, the maintainer
extended the goal to object identity for all query data (SRC-20260926-TTZ7C-61):
JSONTag responses must link shared objects without an `id`, using ids derived
from record numbers for stored objects and per-response ids for objects a query
builds; tagged scalars keep identity within a query. Shared arrays and the
jsontag fallback bug remain out of scope. The cycle is back in Act; the
evaluation-ready section below describes the earlier schema-only state.

## Evaluation ready

The goal can be judged. Schema objects keep identity across the isolate by
stable private handles, JSONTag responses keep the schema file's ids and links,
and guest views read each host property once per query. EVD-20260926-TTZ7C-64
records 205 passing tests, failing baselines, and curriculum-store's full schema
returning in 34 ms as JSONTag and 271 ms as JSON through the actual runtime,
with record-query benchmarks unchanged within variation.

Retained for next-cycle planning, not absorbed: command workers still receive
the schema without JSONTag ids; guest JSONTag serialization of query-built
shared objects without ids needs `crypto`, which the isolate lacks;
curriculum-store's own Spiral state needs repair; nine older non-implementation
artifacts use `sd:changeCausedBy`, which the ontology reserves for
implementations, and the validators do not flag it. Human evaluation,
acceptance and integration remain separate decisions.

A full causal-chain review before acceptance corrected this cycle's own use of
that relation on DES-20260924-TTZ7C-59 (now `sd:constrainedBy`), clarified the
EVD-20260926-TTZ7C-64 timing column, added SRC-20260926-TTZ7C-61 as a cause of
the IMP-20260919-TTZ7C-33 transition, and refreshed the stale project context.

## Evaluation ready (extended goal)

The extended goal can be judged. Stored records keep identity across paths and
cycles; JSONTag responses link shared objects without an `id` as `~<record>`,
stable across queries and updates, or `~query-<n>` for query-built objects,
without exposing those ids to queries; tagged scalars keep identity within a
query. EVD-20260926-TTZ7C-64 records the regressions, 207 passing tests and
about 4% added cost on large scans. Shared-array identity and the jsontag
fallback bug remain deferred, with the earlier retained discoveries.

## Human acceptance

On 2026-09-26, after reviewing the extended evaluation, the maintainer
instructed: "Accepted."

This accepts the cycle at fa6c791991381beb5fac40103dbc9dba15233ee8: stable
schema handles, schema JSONTag text for query workers, per-query read caching,
record-derived and per-response output ids, and per-query tagged scalar
identity, with the evidence and limits in EVD-20260926-TTZ7C-64. Deferred:
shared-array identity, the jsontag `createId` fallback bug, schema ids in
command workers, the nine older `sd:changeCausedBy` uses and curriculum-store's
Spiral repair. No version change was requested. Acceptance authorizes proposing
integration; merging remains a separate decision. Branch identity was verified
before recording acceptance.
