# Design: Optional Index Finalization With Legacy Fallback

Add `finalize(serialized, meta, uuid = null)` to the default index module. Its
default behavior delegates to the existing serialized offset writer. The
argument is the exact OD-JSONTag output (a string for conversion or Uint8Array
for commands), metadata retains the existing shape, and uuid is null for base
conversion or the command ID for a changeset.

Export one `finalizeIndex(index, serialized, meta, uuid = null)` dispatcher
from that module. It invokes the configured index's finalize when present,
otherwise the default. Preserve the configured object's method receiver and
return its promise so both callers await completion and propagate rejection.
Do not mutate or spread the configured object: frozen legacy wrappers and
methods inherited through prototypes should remain usable.

The converter and command worker import only this dispatcher, not the offset
module. Existing create/update/load hooks retain their invocation and mutation
semantics. No additional method is required in curriculum-store. A custom
finalizer owns its finalization behavior and can explicitly delegate to the
default to retain standard offsets while adding custom outputs; the dispatcher
does not invoke both and duplicate writes. Serialized input is read-only by
contract, and finalization must not mutate canonical state.

Keep the existing position relative to data persistence, integrity recording,
and command completion. The final-byte writer and sparse framing behavior do
not change. This supplements DES-20260917-TTZ7C-10 with a compatibility boundary,
not a general handler registration system. Legacy ID/offset writes from custom
pre-serialization hooks remain possible for compatibility.

Verify async completion, rejection, method receiver, custom replacement and
delegation, and fallback for frozen/legacy wrappers. Run a disposable probe
against curriculum-store's actual unchanged index module for both conversion
and a command on a representative graph, then run existing lifecycle suites.
