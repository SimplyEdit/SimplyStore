# Mandatory verification with explicit initialization

Always resolve a manifest path in runtime, converter, loader and inspection.
Ignore the former integrity=false/required=false toggles; they cannot disable
verification. Keep --integrity as a harmless redundant converter flag. Missing
manifest diagnostics direct operators to the explicit initialization workflow.

Factor artifact hash collection and manifest serialization: canonical digest
already verified after finalization plus SHA-256 of final index bytes. Append
all entries with a single durable appendRecord before done; conversion uses the
same set. Administrative replay defers its worker's manifest append to its
coordinator so retained expected digests are checked before replacement hashes
and done. That is an internal publication boundary, not a store opt-out.

Add initializeIntegrity and recover.mjs init-integrity --store config.json.
Acquire normal ownership on all mutable directories, refuse any existing
manifest, inspect an unsealed store via a separate explicit internal entry point,
validate framing/index contents/IDs and decode records through FileDataset.
Require a ready, stable committed prefix. Compare inventory after validation,
then atomically and durably publish hashes from that snapshot for base and
committed changesets and present standard sidecars. Release ownership on read-only
validation failures; retain it if durable publication becomes uncertain.
Never invoke custom hooks or replay commands; never modify data/index/log files.
This establishes trust in current validated bytes, not proof of past correctness.

Normal inspect/load functions remain mandatory; only the named unsealed
validation entry points used by initialization can operate without a manifest.
Existing stores require this operation explicitly. Tests create manifests when
constructing fixtures, not as a side effect of opening the product.

initialization/rejection/no rewrite/lock cases and real command/restart behavior.
Compare repeated local latency runs against accepted 4680c76 with the same
